# 3D 모델

이 폴더에는 프로젝트에서 검토할 GLB 모델과 audit metadata가 들어 있습니다.

## 포함된 파일

- `glb/`
  컴포넌트별로 이름을 정리한 GLB 파일입니다.
- `glb_model_manifest.json`
  실제 프로젝트에서 사용할 모델 후보와 Storage 경로, 파일 크기, bounds, audit
  상태를 정리한 manifest입니다.
- `glb_audit_report.json`
  `DB 에셋` 폴더에 있던 GLB 후보 전체를 검사한 결과입니다.

## 현재 판단

- `ready`: Arduino Uno R3, Arduino Nano, 일반 브래드보드, HC-SR04, LED,
  푸쉬 버튼, SG90 서보모터
- `needs_optimization`: 긴 브래드보드

긴 브래드보드 GLB는 구조상 정상이고 프로젝트에 넣어볼 수는 있지만, 파일 크기가
약 25MB라 웹에서 매번 불러오기에는 무겁습니다. 배포 전에는 Draco/meshopt 압축,
텍스처 축소, 불필요 mesh 제거 같은 최적화를 권장합니다.

## z 좌표가 필요한 경우

이 폴더를 단순히 3D 파일 보관용으로만 쓴다면 핀별 z 좌표는 필수는 아닙니다.
하지만 사용자가 마우스로 돌려보는 실제 3D 회로도에서 점퍼선을 모델 핀에 정확히
연결하려면 핀마다 모델 로컬 좌표 `x_3d`, `y_3d`, `z_3d`가 필요합니다.

주의할 점은 위에서 찍은 PNG 한 장으로는 `z_3d`를 정확히 구할 수 없다는
것입니다. z 좌표는 Blender, GLB, VARCO 같은 3D 모델 안에서 핀 위치를 직접
찍어서 추출해야 합니다.
